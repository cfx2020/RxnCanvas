# Security Policy

## Supported version

Security fixes are currently provided for the latest 0.1.x build only.

## Reporting a vulnerability

Do not attach confidential calculation outputs or a working exploit to a public issue. Report the affected version, operating system, impact and minimal reproduction privately to the person or organization that distributed the RxnCanvas build.

A dedicated public security contact has not yet been configured. Public distribution must not begin until the release owner adds a monitored private security address or repository security-advisory channel here.

## Untrusted project files

Treat project folders, legacy `.rxncanvas.json` files and `.rxncanvas.zip` archives from other people as untrusted input. RxnCanvas applies schema normalization, archive path checks and size limits, but users should retain backups of important projects.

## Disclosure

Please allow reasonable time for investigation and a patched build before public disclosure.
