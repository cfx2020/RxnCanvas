# 窄屏侧栏布局异常 Issue Report

## 1. 问题现象

窄屏窗口中，点击左侧栏按钮后没有看到左侧栏，视觉上像是打开了右侧栏；点击右侧栏按钮后右栏内容消失，但画布右侧仍保留整列空白。窗口进一步变窄时，左侧栏按钮会与 macOS 红绿灯区域重叠。

## 2. 复现步骤

1. 在 macOS 桌面壳或浏览器预览中把工作台缩窄到约 960 CSS px 或更窄。
2. 点击左上角项目侧栏按钮。
3. 观察左栏没有直接显示，右侧 inspector 仍占据视觉焦点。
4. 点击右上角节点侧栏按钮。
5. 观察 inspector 内容消失，但画布右侧仍保留空白区域。
6. 继续缩窄窗口，观察左侧栏按钮与原生红绿灯安全区的间距。

复现频率：稳定。

## 3. 期望 vs 实际

**期望行为**：窄屏下项目侧栏默认自动收起，鼠标移到窗口最左边缘时以悬浮抽屉显示，离开后收回；右按钮只控制节点 inspector，关闭后画布立即占满释放出的空间；macOS 红绿灯和应用按钮保持安全间距。

**实际行为**：左栏状态与右栏网格状态发生视觉串扰，左栏仍依赖旧 hover 抽屉逻辑；右栏关闭后第三列未释放；窄屏标题栏的左按钮安全位置被覆盖。

## 4. 环境信息

- 涉及模块 / 功能：React 工作台、响应式侧栏、Electron macOS 隐藏标题栏
- 相关文件 / 函数：`web/src/app/App.tsx`、`web/src/app/workbench.css`、`web/electron/main.cjs`
- 运行环境：Vite 开发预览与 macOS Electron app
- 其他上下文：用户提供两张窄屏截图；问题在约 951 CSS px 的预览宽度可稳定观察。

## 5. 严重程度

**P1** — 核心图谱编辑工作台在常见窄窗口下出现导航误导和大面积不可用留白，虽可通过放宽窗口绕过，但严重影响正常编辑。
